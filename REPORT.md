 до root, после appuser

 Ответы на вопросы:
 1) Пользователь без привелегий имеет меньше прав, чем root. Если приложение будет взломано, злоумышленник получит меньше возможностей для выполнения опасных действий внутри контейнера
 2) Redis хранит данные счётчика и в нашей конфигурации не защищён паролем. Если опубликовать его порт, постороние смогут попытаться получить доступ к базе и изменить данные. Поэтому Redis доступен только внутри сети Docker Compose.
 3) Открытый SSH-ключ нужен для того, чтобы сервер мог проверить, что подключаешься именно ты, не получая твой закрытый ключ. Закрытый ключ нельзя передавать, он используется для подтверждения личности Владельца
 Закрытый SSH-ключ находится в /id_ed25519, а открытый ключ находится в /id_ed25519.pub
 Передавать можно открытый ключ в котором указано .pub
